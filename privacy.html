Privacy Policy

This policy describes how myWineFridge handles information in the current local-first app.

이 문서는 출시 준비용 초안입니다. 실제 지원 이메일, 수집 SDK, 인증 및 동기화 정책이 확정되면 제출 전에 업데이트해야 합니다.

개인정보 처리방침

시행일: 2026-07-14

1. 처리하는 정보

현재 버전의 myWineFridge는 사용자가 직접 입력한 와인 정보, 셀러 정보, 시음 기록, 메모, 사진, 설정 값을 기기 내부에 저장합니다.

2. 서버 전송

현재 버전은 서버 계정, 서버 동기화, 클라우드 저장 기능을 제공하지 않습니다. 앱 데이터는 사용자가 직접 공유하거나 백업 파일을 내보내지 않는 한 OL Wine Service 서버로 전송되지 않습니다.

3. 백업 파일

사용자가 수동 백업을 만들면 백업 파일에는 와인 데이터, 시음 기록, 설정, 선택한 사진 파일이 포함될 수 있습니다. 백업 파일의 보관과 공유는 사용자 책임입니다.

4. 사진과 권한

앱은 와인 사진과 시음 사진을 저장하기 위해 카메라 또는 사진 접근 권한을 요청할 수 있습니다. 촬영 사진을 사진첩에 함께 저장하는 설정을 켠 경우 사진첩 저장 권한이 사용될 수 있습니다.

5. 분석과 오류 수집

현재 문서 기준으로 공개 출시용 분석 또는 오류 수집 SDK는 확정되지 않았습니다. 해당 기능을 도입하는 경우 수집 항목과 목적을 이 문서에 반영합니다.

6. 계정과 동기화

계정 기능 또는 서버 동기화가 추가되는 경우, 계정 정보, 인증 제공자, 서버 저장 항목, 삭제 절차를 이 문서에 추가로 명시합니다.

7. 문의

지원 이메일은 출시 전 확정 후 이 위치에 게시됩니다.

Privacy Policy

Effective date: 2026-07-14

1. Information handled by the app

The current version of myWineFridge stores user-entered wine information, cellar information, tasting records, notes, photos, and settings on the device.

2. Server transmission

The current version does not provide server accounts, server sync, or cloud storage. App data is not sent to OL Wine Service servers unless the user exports or shares it manually.

3. Backup files

Manual backup files may include wine data, tasting records, settings, and selected photo files. Users are responsible for storing and sharing backup files safely.

4. Photos and permissions

The app may request camera or photo access to add wine and tasting photos. Photo library save permission may be used when the user enables saving captured photos to the device photo library.

5. Analytics and crash reporting

Analytics and crash reporting SDKs for public release are not finalized as of this draft. If they are added, this policy will be updated with the data collected and purpose.

6. Accounts and sync

If account or server sync features are added, this policy will describe account information, authentication providers, server-stored data, and deletion procedures.

7. Contact

The official support email will be published here before store submission.

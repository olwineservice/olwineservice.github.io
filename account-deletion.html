Account Deletion

The current release preparation version of myWineFridge does not provide server accounts.

계정 삭제 안내

현재 버전은 서버 계정 기능을 제공하지 않으므로 삭제할 서버 계정이 없습니다.

기기 안의 앱 데이터를 삭제하려면 앱 설정의 데이터 삭제 기능 또는 운영체제의 앱 삭제 기능을 사용할 수 있습니다.

향후 계정 기능이 추가되면 앱 안에서 계정 삭제 요청을 제공하고, 삭제되는 데이터와 보관되는 데이터를 이 페이지에 명시합니다.

Account Deletion

The current version does not provide server accounts, so there is no server account to delete.

To remove local app data, use the data deletion features in app settings or delete the app from the device.

If account features are added in the future, in-app account deletion will be provided and this page will describe deleted and retained data.

# OL~ WINE Support Site

This repository hosts the GitHub Pages support site for OL~ WINE by OL Wine Service.

Published URL:

```text
https://olwineservice.github.io/
```

## Pages

- `index.html`: landing page
- `about.html`: product introduction
- `features.html`: bilingual overview of major app features
- `support.html`: user support and FAQ
- `privacy.html`: privacy policy, including optional anonymous data contribution
- `terms.html`: terms of use
- `account-deletion.html`: account and local data deletion guidance
- `open-source.html`: searchable full package/asset license notices and exchange-rate sources
- `licenses/<app-version>/NOTICES.txt`: versioned full-text notices
- `licenses/<app-version>/manifest.json`: app version, publication date, counts, and notice checksum
- `404.html`: not found page
- `FEATURE_SCREENSHOT_BRIEF.md`: feature order, capture inventory, and release checks

## Updating Open Source Notices

The license page is generated by `tool/export_open_source_licenses.py` in the sibling `myWineFridge` app repository. Do not edit individual license bodies in the generated HTML. The existing 2026-10-07 inventory is not a completed mobile-distribution audit: it includes development and non-mobile packages and lacks a complete native-library/model review. Do not treat its counts as the components actually shipped.

Build matching iOS and Android release artifacts first. Generate a pending inventory, then review every entry's inclusion and notice-retention obligation against those artifacts:

```bash
python3 tool/export_open_source_licenses.py \
  --notices build/ios/iphoneos/Runner.app/Frameworks/App.framework/flutter_assets/NOTICES.Z \
  --inventory-out /tmp/olwine-license-review.json
```

Complete the review's platform/engine/native-SDK coverage, artifact paths and checksums, per-entry decisions and evidence, and additional required native/model notices. `scope_complete` must remain false while any of these are pending. Only then generate the replacement page:

```bash
python3 tool/export_open_source_licenses.py \
  --notices build/ios/iphoneos/Runner.app/Frameworks/App.framework/flutter_assets/NOTICES.Z \
  --review /path/to/completed-license-review.json \
  --site-dir ../olwineservice.github.io
```

Use the matching `--version` if the build overrides `pubspec.yaml`. The exporter adds bundled Unicode CLDR and Lucide/Feather notices. It does not automatically audit native SDKs, the embedded recognition model, or Flutter engine inclusion. Do not add unrelated iso-codes, desktop-only libraries, development tools, or server-only SDKs just because they appear in a dependency inventory. Conversely, do not omit required transitive notices. See the app repository's `docs/SUPPORT_SITE_REVIEW.md` for the current audit findings. Commit only reviewed outputs; publishing through a push to `main` is a separate step. Existing version directories are preserved.

## Before Store Submission

- Keep the support email current: `olwine.service@gmail.com`.
- Review privacy policy text against the final SDK list, account policy, analytics, crash reporting, anonymous contribution payload, consent flow, and retention behavior.
- Review terms with appropriate legal advice before public store submission.

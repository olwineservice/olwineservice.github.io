# OL~ WINE Support Site

This repository hosts the GitHub Pages support site for OL~ WINE by OL Wine Service.

Published URL:

```text
https://olwineservice.github.io/
```

## Pages

- `index.html`: landing page
- `about.html`: product introduction
- `features.html`: free and Premium feature overview
- `support.html`: user support and FAQ
- `privacy.html`: privacy policy, including optional anonymous data contribution
- `terms.html`: terms of use
- `account-deletion.html`: account and local data deletion guidance
- `open-source.html`: searchable full package/asset license notices and exchange-rate sources
- `licenses/<app-version>/NOTICES.txt`: versioned full-text notices
- `licenses/<app-version>/manifest.json`: app version, publication date, counts, and notice checksum
- `404.html`: not found page
- `FEATURE_SCREENSHOT_BRIEF.md`: requested real-app captures for the feature page

## Updating Open Source Notices

The license page is generated by `tool/export_open_source_licenses.py` in the sibling `myWineFridge` app repository. Do not edit individual license bodies in the generated HTML. After producing the release app, run from that app repository:

```bash
python3 tool/export_open_source_licenses.py \
  --notices build/ios/iphoneos/Runner.app/Frameworks/App.framework/flutter_assets/NOTICES.Z \
  --site-dir ../olwineservice.github.io
```

Use the matching `--version` if the build overrides `pubspec.yaml`. The exporter also includes the app's bundled CLDR, iso-codes, and Lucide/Feather notices. Review and commit `open-source.html` and the generated version directory, then push `main` to publish through GitHub Pages. Existing version directories are preserved.

## Before Store Submission

- Keep the support email current: `olwine.service@gmail.com`.
- Review privacy policy text against the final SDK list, account policy, analytics, crash reporting, anonymous contribution payload, consent flow, and retention behavior.
- Review terms with appropriate legal advice before public store submission.
